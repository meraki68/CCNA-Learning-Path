# Day 18 of My 60-Day Network Engineering Challenge
Today, I explored EIGRP and advanced routing behavior — and this one stretched my understanding.

This wasn’t just about routing… it was about how routers intelligently choose and balance paths.

Here’s what I worked on:
-	Configured IP addressing and hostnames across routers
-	Created loopback interfaces (for stable router identification)
-	Set up EIGRP across all routers
-	Disabled auto-summary for proper route advertisement
-	Configured passive interfaces for efficiency
-	Implemented unequal-cost load balancing

💡 Key Takeaways:
-	EIGRP allows smarter and faster routing decisions
-	Loopback interfaces provide stable router IDs
-	Passive interfaces reduce unnecessary traffic
-	Unequal-cost load balancing allows traffic to use multiple paths efficiently

⚠️ What stood out:
Unlike traditional routing, traffic doesn’t always follow a single path — it can be intelligently distributed.

This is where routing becomes dynamic and optimized.
