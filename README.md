# Day 24 of My 60-Day Network Engineering Challenge
Today, I stepped deeper into the world of IPv6 networking — and it was a completely different mindset from IPv4.

This lab focused on configuring IPv6 across routers and end devices while understanding how addressing and routing behave in modern networks.
 What I worked on today:
- Configured IPv6 addresses on router interfaces using EUI-64
- Calculated the automatically generated Interface IDs before configuration
- Assigned IPv6 addresses and default gateways to PCs
- Enabled IPv6 on router interfaces without manually assigning addresses
- Configured IPv6 static routes between routers
- Verified end-to-end connectivity using ping tests

One of the biggest lessons from today was understanding how EUI-64 automatically creates interface identifiers from MAC addresses.
Instead of manually assigning every host portion, IPv6 can intelligently generate it — which shows just how scalable and efficient IPv6 was designed to be.

Another interesting part was enabling IPv6 on interfaces without explicitly configuring an address. That really opened my eyes to how IPv6 handles link-local communication differently from IPv4.

IPv6 isn’t just “more IP addresses.”
