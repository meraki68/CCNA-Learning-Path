# Day 6 of My 60-Day Network Engineering Challenge

Today was different.
Everything was configured… but nothing worked.

PC1 and PC2 couldn’t communicate — and the task was simple:
👉 Find the problem. Fix it.

Here’s what I did:
-	Verified IP addressing on all devices
-	Checked interface statuses on routers
-	Reviewed routing configurations
- Identified misconfigurations on both routers
- Fixed the issues and restored connectivity

💡 Key Takeaways:
-	Troubleshooting is the real skill in networking
-	One small misconfiguration can break the entire network

  Always follow a step-by-step approach:
- Check IPs
- Check interfaces
- Check routes

⚠️ What stood out:
The configs looked correct at first glance — but digging deeper revealed the issue.

This felt less like a lab… and more like a real-world network issue.
