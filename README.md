# Day 5 of My 60-Day Network Engineering Challenge
Today, I moved beyond basic configs into routing between different networks.

This time, nothing was pre-configured — I had to build everything from scratch.

Here’s what I worked on:
-	Configured IP addresses and hostnames on routers
-	Assigned correct IPs and default gateways to PCs
-	Interpreted a network diagram and implemented it
-	Configured static routes to enable inter-network communication
-	Successfully tested connectivity using ping

💡 Key Takeaways:
-	Devices in different networks cannot communicate without routing
-	Static routes manually define the path packets should take
-	Default gateways are critical for end devices
-	One wrong IP or route = no connectivity

⚠️ What challenged me:
Troubleshooting routing issues when the ping failed initially — small mistakes can break the entire network.

This felt like building a real network from the ground up.
