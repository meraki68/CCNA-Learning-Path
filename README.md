# Day 31 of My 60-Day Network Engineering Challenge
Today’s lab focused on DHCP — one of the most important services in modern networking.
This was a practical deep dive into how devices automatically receive IP configurations and how routers can forward DHCP requests across networks.
Without DHCP, network administration at scale would be extremely difficult.

What I worked on today:
- Configured multiple DHCP pools on R2
- Reserved specific IP address ranges from assignment
- Configured DNS servers and domain names in DHCP pools
- Configured R1’s interface as a DHCP client
- Implemented DHCP relay (IP Helper Address) functionality
- Used PC CLI commands to request IP addresses dynamically
- Verified successful IP address allocation across subnets

DHCP is a major part of network automation and scalability.

The ability to automatically configure devices is one of the reasons modern networks can support thousands of users efficiently.
