# Day 32 of My 60-Day Network Engineering Challenge
Today’s lab introduced me to SNMP (Simple Network Management Protocol) — one of the core technologies used for monitoring and managing network devices in enterprise environments.
This lab gave me practical insight into how network administrators remotely gather information from routers and even make configuration changes.

What I worked on today:
- Configured SNMP communities on a Cisco router
- Set up read-only and read-write SNMP access
- Used SNMP Get messages through a MIB browser
- Retrieved system uptime information
- Queried the router hostname remotely
- Checked router interface details using SNMP
- Explored additional device information available through MIBs
- Used SNMP Set messages to remotely change the router hostname

That really highlighted why SNMP is such an important protocol in network monitoring systems.
I also learned the difference between:
- Read-only communities → monitor information only
- Read-write communities → allow configuration changes
