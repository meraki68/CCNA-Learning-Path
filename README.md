# Day 23 of My 60-Day Network Engineering Challenge
Today’s lab introduced me to something every modern network engineer must understand — IPv6 and Dual-Stack Networking.

With IPv4 exhaustion becoming a global reality, learning IPv6 is no longer optional.

This lab helped me understand how IPv4 and IPv6 can operate together within the same network infrastructure.

Here’s what I configured today:
- Enabled IPv6 routing on the router
- Configured IPv6 addressing on router interfaces
- Verified interface IPv6 addresses and connectivity
- Configured IPv6 addresses on end devices
- Assigned the correct IPv6 default gateways
- Built a functional IPv4/IPv6 dual-stack network
- Tested communication between PCs using both IPv4 and IPv6
- I only made some packet analysis in Wireshak
  
One of the most interesting parts of today’s lab was observing how devices automatically generate link-local IPv6 addresses alongside manually configured global unicast addresses.

The transition from IPv4 to IPv6 is one of the biggest evolutions in networking, and getting hands-on experience with it makes the learning process much more practical and exciting.

Every lab is helping me move from just studying networking… to actually thinking like a network engineer.
